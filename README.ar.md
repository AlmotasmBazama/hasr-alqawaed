# حصر القواعد

تطبيق Flutter عربي لحساب كميات وتكلفة القواعد، مع واجهة RTL ونماذج مخصصة وحفظ محلي وتقارير PDF.

**[تجربة التطبيق](https://hasr-alqawaed-preview.web.app)** · **[English](README.md)** · **[تقرير تجريبي](docs/sample-report.pdf)** · **[تنزيل Android](https://github.com/AlmotasmBazama/hasr-alqawaed/releases)**

## الوظائف

- حساب فوري للخرسانة وحديد 14 وحديد 8 وأجور النجار والحداد والصب.
- إضافة النماذج وتعديلها مع حفظ معرّفاتها، والاحتفاظ بالعدد والأسعار عند تبديل النموذج.
- دعم الأرقام العربية والإنجليزية والفاصل العشري العربي، دون فقد التركيز أثناء الإدخال.
- تخزين JSON بإصدار بنية عبر SharedPreferencesAsync، مع ترتيب عمليات الكتابة والتعامل مع تلف البيانات وفشل الحفظ.
- تقرير A4 عربي بنص وجدول حقيقيين وخط Cairo مضمن، من نتيجة الحساب نفسها المعروضة على الشاشة.
- مشاركة النظام على Android، ومشاركة ملفات المتصفح عند توفرها مع بديل تنزيل PDF.

## صحة الحسابات

الحسبة الأساسية عند 20 قاعدة تساوي **17,800 د.ل**. كمية الخرسانة المعتمدة هي 0.75 م³ لكل قاعدة، وتبقى الأبعاد وصفية. تكلفة حديد 14 تعتمد الكمية الدقيقة 70 ÷ 6.5 وتساوي 5,600؛ التقريب للعرض فقط. الحسبة التجريبية بمعاملات مخصصة تعطي **9,580 د.ل**.

## التشغيل

الإصدار المستخدم: Flutter 3.41.9 وDart 3.11.5. الحد الأدنى لـ Android هو API 24.

```sh
flutter pub get
flutter run
flutter analyze
flutter test
flutter build apk --debug
flutter build web --release --no-web-resources-cdn
```

مجلد APK الناتج: `build/app/outputs/flutter-apk`. يتطلب بناء iOS جهاز macOS وXcode ولم يُتحقق منه. إذا رفضت أدوات Android مسارًا عربيًا على Windows، استخدم مسار عمل بحروف إنجليزية.

## التحقق والتخزين

نجحت 27 حالة اختبار آلي للحسابات والتحقق والتخزين والواجهة وتصدير PDF، إضافة إلى اختبار تكامل Android وفحص محاكي. اختُبرت نسخة الويب محليًا ومن الرابط المنشور بعرض الكمبيوتر والهاتف، بما يشمل إضافة النماذج وتعديلها واستعادتها بعد التحديث وتنزيل تقارير فعلية. فُحصت العربية والخطوط والأرقام داخل التقرير بصريًا.

الحفظ محلي لكل متصفح وأصل رابط، ولا توجد مزامنة بين الأجهزة أو قاعدة بيانات خلفية. لم تُختبر مشاركة الملف إلى تطبيق خارجي من متصفح هاتف فعلي. تفاصيل التنظيم والتشغيل والنشر موجودة في [README الإنجليزي](README.md).

الخط محلي وترخيصه في [OFL.txt](assets/fonts/OFL.txt). طُوّر المشروع بمساعدة أدوات ذكاء اصطناعي مع التحقق بالاختبارات وتجارب Android والمتصفح.
